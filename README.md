# Media Tracker

A responsive media discovery and tracking application built with Angular and Tailwind CSS. The application allows users to browse, search, and explore movies and TV shows using data from The Movie Database (TMDB) API.

# Features
- Search movies and TV shows by title
- Discover trending and popular media
- Filter content by genre, release date, rating, and keywords
- Sort results by popularity, rating, and release date
- View detailed information about movies and TV shows
- Responsive design optimized for desktop and mobile devices
- Interactive UI with custom dropdowns, date pickers, and media cards

  
# Tech Stack
- Angular
- TypeScript
- Angular Signals
- RxJS
- Tailwind CSS
- TMDB API
- HTML5 & CSS3

# Installation
1. Clone the repository
```
git clone https://github.com/your-username/media-tracker.git
```
2. Navigate to the project directory
```
cd media-tracker
```

3. Install dependencies
```
npm install
```
4. Start the development server
```
ng serve
```
5. Open your browser and navigate to:
```
http://localhost:4200
```

## Environment Variables

Create a `.env` file in the server directory:

```env
TMDB_API_KEY=your_tmdb_api_key
TMDB_BASE_URL=https://api.themoviedb.org/3
PORT=3000
```

## Running the Application

### Start the backend

```bash
cd server
npm install
npm start
```

### Start the frontend

```bash
npm install
ng serve
```

# API

This project uses The Movie Database (TMDB) API to fetch movie and TV show data.
